# hybrid-music-recommender
2026 team 11 Machine Learning Term Project · Fall 2026

Objective

음악의 음향 특징과 사용자 청취 이력을 결합해 Cold-Start 문제를 개선하는 하이브리드 음악 추천 시스템

Methods

Content-Based Filtering — K-Means++, TF-IDF, Cosine Similarity
Collaborative Filtering — Matrix Factorization, SGD
Weighted Hybrid Filtering — Adaptive Weighting, Top-N Recommendation Datasets
MSD + Spotify + Last.fm
Spotify 30,000 Songs Evaluation
Silhouette Score, Precision@K, Recall@K, NDCG@K
