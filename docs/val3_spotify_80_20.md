## 1. 실험 목적

기존 평가는 MSD(`Music Info.csv` + `User Listening History.csv`) 하나의 데이터셋 안에서 학습 곡의 10%를 인위적으로 지운 **모의 신곡**으로 진행했습니다. 이 단계의 목적은 모델을 새로 학습하거나 하이퍼파라미터를 다시 튜닝하는 것이 아니라, **MSD에서 확정한 최종 모델(`β=0.9, γ=5, 아티스트당 최대 5곡 제한`)이 완전히 새로운 외부 데이터셋(`spotify_songs.csv`)과 실제 Cold-Start 환경에서도 그대로 잘 작동하는지 검증**하는 것입니다.

추천 시스템에서 사용자가 직접 만든 플레이리스트는 하나의 일관된 청취 이력과 같습니다. 따라서 각 플레이리스트의 **80%를 입력 이력(`playcount = 1`)**으로 주고, 모델이 **숨겨진 나머지 20%의 곡**을 전체 후보군(26,159곡)에서 다시 찾아낼 수 있는지 비교합니다.

## 2. 데이터 연결 및 평가 방법

**1) 카탈로그 연결 (문자열 매칭)**
`Music Info.csv`(50,683곡)와 `spotify_songs.csv`(고유 정규화 키 기준 26,159곡)에서 아티스트와 곡명을 정규화한 키를 만듭니다.

```python
norm_key = artist.str.lower().str.strip() + " - " + name.str.lower().str.strip()
```

- **MSD Warm 곡 (겹치는 곡):** 두 데이터셋에서 `norm_key`가 일치하는 **2,146곡(8.2%)**은 `Music Info.csv`의 `track_id`로 매핑합니다. 이 중 학습 청취 이력이 존재하는 **313곡(1.2%)**은 음향 유사도($S_{CB}$)와 협업 필터링 점수($S_{MF}$)를 모두 가집니다.
- **Cold-Start 곡 (안 겹치는 곡):** 일치하지 않는 나머지 **24,013곡(91.8%)**은 기존 Spotify `track_id`를 유지합니다. 학습 청취 이력이 전혀 없으므로 $S_{MF} = 0$이고 $S_{CB} > 0$인 실제 신곡(Cold-Start) 역할을 합니다.
- **겹치는 비율이 8.2%인 이유:** `Music Info.csv`는 발매 연도 중앙값이 **2006년**(2015년 이후 곡 비율 3.6%)인 반면, `spotify_songs.csv`는 중앙값이 **2017년**(2015년 이후 곡 비율 62.9%)인 최신 스트리밍 데이터여서 시대 차이가 크기 때문입니다.

**2) 80/20 플레이리스트 분할**
- 고유 곡 수가 **10곡 이상인 플레이리스트 460개**를 대상으로 평가합니다(시드 42 고정).
- 각 플레이리스트의 80%는 입력 청취 이력(`playcount = 1`), 20%(총 6,412곡)는 숨겨진 정답으로 분리합니다.
- 입력된 80% 곡만으로 Content-Based 프로필 벡터와 ALS Fold-in 사용자 벡터를 구한 뒤, 이미 들은 80% 곡을 제외한 전체 후보(26,159곡)에서 Top-$K$($K=5, 10, 20$)를 추천합니다.

**3) 비교 모델 (추가 튜닝 없음)**
- **CB:** 1단계 Content-Based 모델 (12개 음향 특징 코사인 유사도)
- **MF:** 2단계 ALS 협업 필터링 (80% 입력 중 Warm 곡으로 사용자 벡터 Fold-in)
- **Hybrid:** 3단계 제안서 가중 결합 공식 ($\alpha(i) = 0.25 + 0.75 / (1 + n_i / 25)$)
- **Final:** 3단계 최종 아티스트 하이브리드 모델 (`final_model.py`의 고정 설정: $\beta=0.9, \gamma=5, \text{Top-10당 아티스트 최대 5곡}$)

## 3. 실험 결과 분석

| 모델 | Hit@5 | Recall@5 | Hit@10 | Recall@10 | NDCG@10 | Hit@20 | Recall@20 | Top-10 내 Cold 곡 비율 |
| --- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **CB** | 0.0739 | 0.0067 | 0.1130 | 0.0109 | 0.0164 | 0.1609 | 0.0155 | 98.8% |
| **MF** | 0.0109 | 0.0011 | 0.0174 | 0.0018 | 0.0024 | 0.0348 | 0.0035 | 66.7% |
| **Hybrid (제안서 공식)** | 0.0717 | 0.0064 | 0.1109 | 0.0107 | 0.0161 | 0.1587 | 0.0153 | 99.3% |
| **Final (최종 모델)** | **0.4304** | **0.0703** | **0.5500** | **0.1164** | **0.1749** | **0.6565** | **0.1710** | 97.8% |

1. **MF 단독 모델의 한계 (`Hit@10 = 1.7%`, `Cold Recall@20 = 0.0012`):**
   후보 곡의 98.8%가 ALS 학습 이력이 없는 Cold-Start 곡이고, 전체 플레이리스트 중 33.3%만 80% 입력에 MF 학습 곡을 포함합니다. 그 결과 MF는 이력이 있는 Warm 정답 곡은 잘 찾지만(`Warm Recall@20 = 0.1244`), 대다수를 차지하는 Cold-Start 곡을 전혀 추천하지 못해 전체 정확도가 가장 낮습니다.

2. **제안서 공식(Hybrid)의 쏠림 현상 재현 (`Warm Recall@20 = 0.0075`):**
   MSD 실험에서 확인했던 동적 $\alpha$의 쏠림 현상이 외부 데이터셋에서도 똑같이 나타납니다. 이력이 없는 Cold-Start 곡은 $\alpha = 1.0$이 되어 $S_{CB}$ 점수를 그대로 받는 반면, 이력이 있는 Warm 곡은 낮은 $S_{MF}$와 결합되며 점수가 깎여 Top-10의 99.3%가 Cold-Start 곡으로 채워지고 `Warm Recall@20`이 CB(0.0224)보다도 낮은 0.0075로 떨어집니다.

3. **최종 모델(Final)의 일반화 성능 입증 (`Hit@10 = 55.0%`, `Hit@20 = 65.7%`):**
   별도의 재튜닝 없이 MSD에서 선택한 최종 모델을 그대로 적용했을 때, **전체 플레이리스트의 55.0%(Top-10) 및 65.7%(Top-20)에서 숨겨진 정답 곡을 최소 1개 이상 맞혔으며**, `NDCG@10`(0.1749)과 `Recall@20`(0.1710) 모두 CB와 제안서 공식 대비 **10배 이상** 높습니다.
   - 실제 Spotify 플레이리스트에서도 숨겨진 20% 정답 곡 중 **46.8%**가 입력 80%에 등장했던 아티스트의 다른 곡이기 때문에, 아티스트 선호도($\beta=0.9$)와 아티스트 기반 $S_{MF}$ 추정($\gamma=5$)이 Cold-Start 곡(`Cold Recall@20 = 0.1721`)과 Warm 곡(`Warm Recall@20 = 0.1070`) 양쪽을 동시에 끌어올립니다.
   - 다만 MSD 실험과 마찬가지로, 입력 80%에 한 번도 등장하지 않은 아티스트의 신곡은 아티스트 점수를 받지 못해 음향 유사도($S_{CB}$)에만 의존한다는 구조적 특성은 동일하게 유지됩니다.
